# Contributing to ElastiCluster

ElastiCluster is source-available and in development.

## Who can contribute

Code contributions are by invitation for now. We don't accept unsolicited pull requests yet; outside contributions
open once a contributor agreement is in place, and this page will say so. Until then you can help by:

- reporting bugs or suggesting features in the issues of the relevant repository;
- reporting security problems privately, as the [security policy](SECURITY.md) describes;
- writing to hello@elasticluster.com.

## For invited contributors

A repository's own `CONTRIBUTING.md`, `AGENTS.md` and README take precedence over this page. In short:

- Branch from `main` and open a pull request; one task per pull request.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
- Changelogs come from fragments in `changelog.d/`; never edit `CHANGELOG.md` or version numbers by hand.
- New dependencies need approval before they are added.
- Tests ship with the change, and required checks pass on the final code.

Taking part means following the [code of conduct](CODE_OF_CONDUCT.md).

# Security policy

Please report vulnerabilities privately to **security@elasticluster.com**, or through GitHub's private vulnerability
reporting on the affected repository (**Security → Report a vulnerability**). Do not open public issues, discussions
or pull requests for security problems.

Include the affected repository, version or commit, the impact, and steps to reproduce. We acknowledge reports within
three working days and keep you informed until a fix ships. Coordinated disclosure: please give us 90 days, or less by
agreement, before publishing details.

Supported versions: the latest pre-release until v1.0; afterwards the current and previous minor release.
